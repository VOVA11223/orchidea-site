# Orchidea — Design Files

B2B оптовый магазин искусственных цветов. Статические HTML-макеты всех страниц.

## Открытие файлов

Просто открой любой HTML-файл в браузере (двойной клик или `open`).

## Страницы

### Публичный сайт (`/pages/`)
| Файл | Страница |
|------|----------|
| `home.html` | Главная страница (гость — цены скрыты) |
| `catalog.html` | Каталог с фильтрами, сортировкой, грид товаров |
| `product.html` | Карточка товара (авторизован — цена видна) |
| `cart.html` | Корзина с прогрессом минимального заказа |
| `checkout.html` | Оформление заказа (доставка, оплата) |
| `account.html` | Личный кабинет (дашборд, заказы) |
| `login.html` | Вход по телефону + СМС-код |
| `register.html` | Регистрация юридического лица (шаги) |

### Админ-панель (`/pages/admin/`)
| Файл | Страница |
|------|----------|
| `dashboard.html` | Дашборд с метриками, графиком, заявками |
| `products.html` | Список товаров с массовыми действиями |
| `orders.html` | Заказы с фильтрами и inline-статусами |
| `customers.html` | Покупатели + очередь одобрения |
| `pricing.html` | Группы цен, скидки, минимальный заказ |

### Дизайн-токены
| Файл | Содержимое |
|------|------------|
| `tokens.json` | Цвета, типографика, отступы, тени |
| `tailwind.config.js` | Конфиг для Next.js проекта |

## Цветовая палитра

| Роль | Значение |
|------|----------|
| Primary (тёмный зелёный) | `#1C3829` |
| Primary dark (для sidebar) | `#111C16` |
| Accent (натуральный зелёный) | `#4A8C5C` |
| Background | `#F8FAF8` |
| Surface (карточки) | `#FFFFFF` |
| Border | `#E2E8E4` |
| Text | `#1A2420` |
| Text muted | `#5A6B62` |

## Шрифты

- **Playfair Display** — заголовки, бренд
- **Inter** — весь UI
